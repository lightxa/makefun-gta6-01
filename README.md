Solmar Bay is an original open-world crime game set in a sun-soaked fictional coastal city: explore on foot or by car, steal vehicles, outrun police Interceptors as your wanted stars climb, and work off a $4,000 debt across five story missions with combat, pickups, a live minimap, day and night, and synthesized WebAudio sound. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
